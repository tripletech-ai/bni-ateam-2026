# 年會現場 — 十種使用者情境

> **用途**：志工培訓、實機驗收、週六現場引導夥伴操作  
> **最後更新**：2026-06-26  
> **適用版本**：底部 Tab「首頁／找人脈／標記與成果／動態」

## 情境 1：第一次掃碼進場

**角色**：從未用過 App 的來賓  
**觸發**：掃描現場 QR Code

### 操作步驟

1. 開啟網站 → 看見 Google 登入畫面
2. 點「使用 Google 登入」→ 選帳號
3. 若不在名單：選「我是新來賓」→ 填姓名、分會、產業等
4. 若在名單：搜尋自己姓名 → 點選認領
5. 完成 7 步新手教學 → 進入首頁

### 成功畫面

- 頂部 UserBar 顯示「你好，{姓名}」
- 首頁「夥伴上線人數」有數字
- 底部四個 Tab 可切換

### 常見卡關

| 問題 | 引導 |
|------|------|
| Google 登入失敗 | 換瀏覽器、確認網路、勿用無痕＋封鎖第三方 Cookie |
| 找不到自己名字 | 改走「新來賓」或請管理員新增 |
| 教學關不掉 | 必須滑完 7 步或點「稍後」 |

## 情境 2：舊會員認領身分

**角色**：已在 `bni_members` 名單、首次登入  
**觸發**：Google 登入後進入認領流程

### 操作步驟

1. 登入後選「我在名單上」
2. 輸入姓名關鍵字（如「王」）
3. 點選正確的那一筆（注意分會）
4. 確認綁定 → 進入教學或首頁

### 成功畫面

- `status` 變為 `claimed`
- 搜尋結果中自己的卡片有完整 have／want 資料

### 驗收重點

- 綁錯人 → 管理員「解除綁定」後重選
- 同姓多人 → 以**分會 + 產業**辨識

---

## 情境 3：AI 一句話找人

**角色**：已登入、想快速媒合  
**觸發**：首頁或找人脈輸入自然語句

### 操作步驟

1. 進入「找人脈」分頁（或首頁 AI 框）
2. 輸入例句：「我是做保險的，想找企業主或會計師」
3. 點「AI 幫我找」→ 等待分析
4. 查看「精準的媒合」與「可能有的機會」
5. 點卡片展開 → 按「想約 1-1」

### 成功畫面

- 至少 1 位精準媒合，或下方有建議人選
- 按鈕變為 active 狀態
- 「標記與成果」Tab 出現 badge

### 驗收重點

- AI 慢或失敗 → 改用分會 chips 或產業圓餅圖篩選
- 搜尋具體產業（律師、室內設計）比「企業主」更準

---

## 情境 4：依分會／產業瀏覽

**角色**：想認識同分會或同產業夥伴  
**觸發**：不想打長句，直接點選篩選

### 操作步驟

1. **找人脈** → 看產業分布圓餅圖與快速篩選列
2. 點「長輝分會」或「金融保險」等 chip
3. 瀏覽同頁結果列表
4. 或 **首頁** → 大產業分布 → 同頁展開結果（不跳頁）

### 成功畫面

- 列表標題顯示分會名或產業名
- 人數與 chip 上數字一致

### 驗收重點

- 白底白字 chip → 已修復深色主題樣式
- 「瀏覽全部分會」可折疊展開完整分會

---

## 情境 5：互相連結（雙向 1-1）

**角色**：積極建立人脈的夥伴  
**觸發**：看到想認識的人

### 操作步驟

1. 在卡片上按「想約 1-1」（A 標記 B）
2. 請 B 也打開 App，在 A 的卡片上按「想約 1-1」（B 標記 A）
3. 雙方皆標記後：
   - 卡片顯示「互相連結 ✓」
   - 首頁「互相連結」數字 +1
   - 動態牆出現「🤝 A 與 B 互相連結了！」（需後端 RPC）

### 成功畫面

- 標記與成果 → 統計格「互相連結」增加
- 今日目標進度條前進
- 動態 Tab 排行榜分數上升

### 規則說明（可唸給夥伴聽）

> 只有**雙方都按**「想約 1-1」才算連結成功，才會上連結王排行榜。

---

## 情境 6：邀請旁邊的人加入

**角色**：已登入、想拉同桌夥伴一起用  
**觸發**：發現旁邊的人還沒開 App

### 操作步驟

1. 進入「找人脈」
2. 看見「邀請旁邊的人加入」橫幅
3. 請對方掃橫幅上的 QR，或點「複製加入連結」傳 LINE
4. 對方掃碼 → 走情境 1 或 2

### 成功畫面

- 現場上線人數（首頁）逐漸增加
- 動態牆可出現「XXX 剛加入現場連結」

### 志工話術

> 掃一下這個碼，用 Google 登入，找到你的名字按認領，就可以開始標記想約 1-1 的夥伴了！

---

## 情境 7：動態牆廣播需求

**角色**：有明確資源需求（找廠商、找合作）  
**觸發**：想讓全場看見自己的需求

### 操作步驟

1. 點底部「動態」Tab
2. 捲到「群組廣播」輸入框
3. 輸入例：「我在找企業主合作室內設計案，歡迎私訊」
4. 點「發布」

### 成功畫面

- Toast「已發布到動態牆」
- 列表最上方出現自己的姓名、分會、訊息

### 限制

- **每分鐘限發 1 則** — 太快會提示請稍候
- 需已綁定會員身分

---

## 情境 8：連結王排行榜

**角色**：愛競賽、想知道自己排名  
**觸發**：聽到主持人口播「連結王」

### 操作步驟

1. **首頁** 捲到「連結王排行榜」看前 5 名預覽
2. 點「查看完整排行榜與動態」→ 進入動態 Tab
3. 查看即時前 30 名（每 20 秒自動更新）

### 成功畫面

- 前 3 名有金／銀／銅色名次徽章
- 顯示姓名、分會、互相連結人數

### 空狀態

- 尚無人上榜 → 引導回情境 5 開始互相標記

---

## 情境 9：完善個人資料

**角色**：產業或引薦欄位空白  
**觸發**：首頁金色「完善資料」橫幅，或 UserBar 按鈕

### 操作步驟

1. 點橫幅或 UserBar「完善資料」
2. 進入 `#profile` 編輯頁
3. 選 1–2 個大產業
4. 填「我有的資源」「想認識」「引薦對象」（可用範本）
5. 儲存 → 回首頁，橫幅消失

### 成功畫面

- 別人搜尋你的產業時更容易找到你
- AI 媒合品質提升

### 引薦格式建議

```
好的引薦：…
理想引薦：…
夢幻引薦：…
```

## 情境 10：管理員現場支援

**角色**：`b1993614@gmail.com` 或 `tripletech.ai@gmail.com`  
**觸發**：夥伴登入／綁定／資料異常

### 操作步驟

1. 自己先完成登入與綁定
2. 底部出現第五個 Tab「管理」
3. 查看：綁定數、教學完成率、最近登入
4. 必要時：解除錯誤綁定、編輯會員欄位、分會合併

### 成功畫面

- Dashboard 數字與現場狀況大致吻合
- 解綁後夥伴可重新認領
