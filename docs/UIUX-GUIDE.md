# UI/UX 設計與檢視指南

> **最後更新**：2026-06-26  
> **適用**：BNI A Team 2026 年會商務連結 App（約 800 人現場、手機為主）

---

## 1. 設計目標

| 目標 | 實作方式 |
|------|----------|
| 現場快速找人 | 首頁 AI 入口 + 搜尋分頁 + 分會 chips |
| 年長學員可用 | 右上角字體三級（標準／大／特大） |
| 雙語 | 中文／EN 切換，會員資料欄位不翻譯 |
| 尖峰穩定 | 會員名單一次載入、本機標記、搜尋離線可用 |
| 集體參與感 | 800 人刷人脈進度條 + 邀請文案複製 |
| 媒合品質 | 鼓勵填產業別與引薦（好／理想／夢幻） |

---

## 2. 資訊架構（分頁）

```
登入閘道 → 認領／綁定 → 新手教學（全屏）→ 主應用

底部 Tab（5 + 管理員）
├── 首頁   #home     Hero、800 挑戰、AI、統計、Contributor、分會
├── 搜尋   #search   AI + 結果 + 分會瀏覽
├── 標記   #marks    本機 1-1 / 商務標記
├── 成果   #result   今日標記進度（目標 5 人）
├── 幹部   #leaders  區域／分會幹部名錄
└── 管理   #admin    僅管理員 Gmail

隱藏路由（無 Tab，可深連結）
└── 我的資料 #profile  產業別、引薦、LINE
```

**進入「我的資料」**：首頁藍色提示條、頂部 UserBar「我的資料」、首頁快捷按鈕。

---

## 3. 首頁視覺層級（由上而下）

1. **Hero** — 品牌標題（鎏金動效 `hero-title-gold`）
2. **完善資料提示** — 僅資料不完整時
3. **800 人挑戰** — 登入頁／首頁進度（`Collect800Game`）
4. **楊董介紹卡** — 照片 + 簡介 + 導向領導層（`YangIntroCard`）
5. **董顧** — 預設摺疊；展開為李鴻毅區董 + 電子名片
6. **顧問群** — 預設摺疊；中山／三蘆董顧名單
7. **系統開發者** — 預設摺疊；王祈、李孟一介紹
8. **主 CTA** — 「開始找人」→ `#search`

**原則**：楊董與行動在上；董顧／顧問／開發者資訊可摺疊，避免首屏過長。

## 4. 關鍵互動模式

### 會員卡片（PersonCard）

- 點擊標題區 **展開／收合** 詳情（非按鈕區）
- 展開後：我有的資源、想認識、引薦對象、LINE / 1-1 / 商務
- 搜尋結果有 **符合項數** 徽章

### AI 搜尋

- **輸入格式**：四行標籤【我是】【我提供】【想找】【不要】；三個範例 chip 可一鍵帶入
- 輸入 ≥2 字 → **三層思考動畫**（≥4.5 秒）→ 列出媒合結果
- 等待時顯示「有 AI 相關開發請找王祈」；結果含思考摘要 + 意圖標籤
- **切 Tab 再回來**：AI 媒合結果保留（`sessionStorage` / `searchSession.js`），按「重新輸入」清除
- 搜尋進行中隱藏分會瀏覽；「重新搜尋」後恢復
- **瀏覽全部分會**：金色卡片、預設展開，分會 chip 可點名單

### 登入／訪客

- 登入頁可設語言、字體（登入前）
- **登入 vs 不登入** 雙欄對照後，可選「先看看，不登入」
- 訪客：可看名單與試 AI；**無法**被搜尋、標記、聊天

### 認領完成彈窗（FirstRunHint）

- 「歡迎加入 800 人挑戰」+ 三步驟 + 進度條 + 邀請連結

### 首頁董顧 accordion

- `bindLeaderEvents` 使用 AbortController，避免重複綁定導致點兩次才開
- 李鴻毅列可點整列開啟電子名片

### 標記

- 僅存 **本機**；清除瀏覽器資料會消失
- Tab「標記」徽章顯示數量

### 新手教學

- 全屏 overlay，7 步，完成寫入 DB
- 支援 `{name}`、`{branch}` 個人化

## 5. 無障礙與行動裝置

| 項目 | 狀態 | 說明 |
|------|------|------|
| 字體縮放 | ✅ 已允許 | 已移除 `user-scalable=no` |
| 焦點環 | ✅ | Tab、按鈕、chips 有 `focus-visible` |
| 圖示按鈕 | ✅ | 字體／語言／登出有 `aria-label` |
| Toast | ✅ | `aria-live="polite"` |
| 減少動效 | ✅ | `prefers-reduced-motion` 關閉入場動畫 |
| 安全區域 | ✅ | Tab bar、body 使用 `safe-area-inset` |
| 觸控 | ✅ | `touch-action: manipulation` |
| 跳過導覽 | ✅ | Skip link 至主內容 |
| 色票對比 | ⚠️ | 金色小字在深色底需現場實機確認 |

## 7. 已知限制與取捨

| 限制 | 原因 | 現場建議 |
|------|------|----------|
| 標記不進 DB | 隱私、尖峰減載 | 提醒夥伴截圖或記在紙上備份 |
| 會員名單全量載入 | 簡化、116–800 人可接受 | 尖峰前確認 DB 連線 |
| AI 需網路 + OpenAI | 三層思考 + 意圖解析 | 斷線時用關鍵字／分會瀏覽 |
| AI 結果 session | 切 Tab 保留媒合；關分頁或「重新輸入」清除 | 志工可提醒「結果會留著」 |
| `#profile` 無 Tab | 減少底部導覽複雜度 | 用首頁提示與 UserBar 引導 |
| 深色主題固定 | 年會品牌視覺 | — |
| OG 圖需完整 URL | 相對路徑 LINE 預覽可能失效 | 部署後更新 `index.html` og:url / og:image |

## 8. 搜尋品質備註

- **產業別**（`profession`）權重最高 — 務必鼓勵填寫
- 搜「室內設計」「律師」等具體產業：**準**
- 搜「企業主」「客戶」等抽象詞：**偏廣**（常命中 wantMeet 文案）
- 測試腳本：`scripts/business-search-quality.mjs`

## 10. 修改 UI 時的檢查清單

- [ ] 新增字串是否加入 `translations.js` 中英兩欄？
- [ ] 按鈕是否可鍵盤操作（Enter／Space）？
- [ ] 表單欄位是否有 label 或 `aria-label`？
- [ ] 長文案是否 `word-break`／`pre-wrap`？
- [ ] 新動畫是否尊重 `prefers-reduced-motion`？
- [ ] 現場流程是否仍「3 次點擊內」可到核心功能？
